## 💻 Practice Session Breakdown

### Day 1: Variables, Input, and Arithmetic

**Focus:** Working with user input and mathematical operations.

| Exercise | Description & Techniques Used |
| :--- | :--- |
| **Personalized Greeting** | Prompted the user for `name` (string) and `age` (integer) and used f-strings for formatted output. |
| **4-Digit Reversal** | Solved a complex math problem by using **Floor Division (`//`)** and the **Modulus Operator (`%`)** to isolate and reverse the digits of an integer. |
| **Simple Calculator** | Created a basic calculator demonstrating addition, multiplication, division, exponentiation (`**`), and square root (`**0.5`), utilizing `float()` to safely handle decimal inputs. |

### Day 2: Control Flow and Data Structures

**Focus:** Implementing logic, iteration, and basic data handling.

| Exercise / Topic | Description & Techniques Used |
| :--- | :--- |
| **Security Door Access** | Implemented a basic **access control system** using `if/elif/else` for input validation and string comparison to check a secret code. |

| **Interactive Menu** | Demonstrated the use of a **`while` loop** to repeatedly present options to the user until a valid exit condition is met. |
| **FizzBuzz Challenge** | Solved the classic problem using a **`for` loop** over a `range(1, 101)` and nested `if` statements to check for divisibility by 3, 5, or both. |
